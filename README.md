# 🎯 QR Code Generator App

A sleek and simple **QR Code Generator Web App** built with **HTML, CSS, and JavaScript**, designed to instantly convert any text or link into a scannable QR code — all right from your browser! 💻✨

---

##  Features

* 🔹 **Instant QR Code Generation** — Type any text or paste a URL, click *Generate*, and get your QR instantly.
* 🔹 **Download QR Code** — Save your QR as a high-quality PNG image.
* 🔹 **Responsive UI** — Works beautifully on both desktop and mobile devices.
* 🔹 **Lightweight & Fast** — No backend required, pure front-end magic!
* 🔹 **Clean & Modern Design** — Minimal layout with smooth styling.

---

##  How It Works

1. Enter any text, link, or message in the input box.
2. Click the **Generate QR Code** button.
3. A fresh QR image appears instantly below.
4. Use the **Download** button to save it to your device.

---

## Installation & Usage

1. **Clone the repository**

   ```bash
   git clone https://github.com/yourusername/qr-code-generator.git
   cd qr-code-generator
   ```

2. **Run locally**

   * Simply open `index.html` in any modern browser.
     *(No server required!)*
